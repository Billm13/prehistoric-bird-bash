# Prehistoric Bird Bash

A top-down pixel-art browser game built for a Stanford Continuing Studies vibe coding class.

Bait, stun and tag 10 different prehistoric birds for your Bird Book. Catch poachers in the act for bonus points (top score 150), and stay clear of the dinosaurs. You have 3 hearts.

**Play:** https://billm13.github.io/prehistoric-bird-bash/

## Controls
- Arrows or WASD: walk and aim
- Space: fire blowgun
- E or Enter: tag a stunned bird or jail a stunned poacher
- B: drop bait · Q: swap blowguns · 1–4: travel · P: pause · M: sound

The whole game is one file, `index.html` (HTML, CSS and JavaScript, no build step).
